# GeoFEM Web Solver v2.7

Κώδικας υπολογισμού καθιζήσεων κυκλικών και απειρομήκων (λωριδωτών) θεμελίων σε γραμμικά ελαστικό έδαφος, με τρεις μεθόδους που συγκρίνονται στο ίδιο διάγραμμα: θεωρία ελαστικότητας (Boussinesq), προσεγγιστική μέθοδος n:1 και πεπερασμένα στοιχεία (FEM).

Π. Πελέκης, Αναπλ. Καθηγητής, Τμήμα Πολιτικών Μηχανικών, Πανεπιστήμιο Πατρών.

**Εφαρμογή:** https://takispelekis-lgtm.github.io/geofem-web-solver/

**Εγχειρίδιο:** [GeoFEM Web Solver - Εγχειρίδιο χρήσης και θεωρία (PDF)](2026_11_09_geofem_web_solver%20-%20Εγχειρίδιο%20χρήσης%20και%20θεωρία.pdf) · [Word](2026_11_09_geofem_web_solver%20-%20Εγχειρίδιο%20χρήσης%20και%20θεωρία.docx)

## Τι υπολογίζει

- Καθίζηση με το βάθος κάτω από κυκλικό πέδιλο (αξονοσυμμετρία) ή λωρίδα (επίπεδη παραμόρφωση), για εύκαμπτο φορτίο ή άκαμπτη πλάκα.
- Προφίλ μέτρου ελαστικότητας: γραμμικό με το βάθος, εκθετικό ή στρωσιγενές.
- Καθίζηση της επιφάνειας από το FEM σε πέντε σταθερά σημεία: κέντρο, άκρη, και B/4, B/2, B έξω από την άκρη.
- Χάρτες (heatmap) μετακινήσεων, τάσεων και παραμορφώσεων από το FEM, με παραμορφωμένο κάνναβο και βέλη φόρτισης.
- Παραμετρική ανάλυση ως προς το φορτίο και τη διάμετρο ή το πλάτος του πεδίλου.

Η θεωρία, οι εξισώσεις, παραδείγματα επαλήθευσης και μια μελέτη περίπτωσης για τον κατάλληλο λόγο n της μεθόδου n:1 βρίσκονται στο εγχειρίδιο.

## Τοπική εκτέλεση

Η εφαρμογή είναι ένα μόνο αρχείο, το `geofem_web_solver.html`. Κατεβάστε το και ανοίξτε το σε έναν σύγχρονο browser· δεν χρειάζεται εγκατάσταση. Όλοι οι υπολογισμοί γίνονται στον browser. Χρειάζεται σύνδεση στο διαδίκτυο μόνο για τη μορφοποίηση και τα εικονίδια, που φορτώνονται από CDN (Tailwind CSS, Phosphor Icons).

Κάθε αλλαγή που ανεβαίνει στον κλάδο `main` δημοσιεύεται αυτόματα στο GitHub Pages.
